# Number Guessing Game 🐍

A Python number guessing game where players try to guess a randomly generated number. The game includes difficulty levels, hints, scoring, and winning streaks.

## Features

- 🎮 Three difficulty levels: Easy, Medium, and Hard
- 🔢 Randomly generated numbers
- 💡 High/low hints to help players guess
- 🎯 Closeness hints when the guess is near the correct number
- 🏆 Scoring system and winning streaks
- 🔄 Replay without restarting the program
- ⏸️ Pause and resume options
- 🛡️ Handles invalid inputs

## Technologies Used

- Python
- Python `random` module

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   `python number_guessing_game.py`
